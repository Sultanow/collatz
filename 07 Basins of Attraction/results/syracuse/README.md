# Exact Syracuse distribution: reference results

The files in this folder were generated by the exact-arithmetic reference
script [`../../C/syracuse_exact.py`](../../C/syracuse_exact.py).

The script computes the finite distribution of the 3-adic Syracuse random
variable by the recursion

`S_n = 2^{-G} (1 + 3 S_{n-1}) mod 3^n`,

with `P(G=k) = 2^{-k}` for integers `k >= 1`.
No Monte Carlo sampling is involved.

## Reproduce

From the `07 Basins of Attraction` directory:

```bash
python C/syracuse_exact.py --max-n 5 --print-distribution
python C/syracuse_exact.py --max-n 7
```

Compare the two commands' outputs to `EXACT_TEST_RESULTS.txt` and
`EXACT_TEST_RESULTS_N7.txt` respectively. For example on Linux:

```bash
python C/syracuse_exact.py --max-n 5 --print-distribution | diff - results/syracuse/EXACT_TEST_RESULTS.txt
python C/syracuse_exact.py --max-n 7 | diff - results/syracuse/EXACT_TEST_RESULTS_N7.txt
```

Known internal reference checks: for `n=1`, numerator vector `[0,1,2]`
with denominator `3`; for `n=2`, numerator vector
`[0,8,16,0,11,4,0,2,22]` with denominator `63`.

**Scope:** exact small-`n` reference and regression checks only. The current
implementation is not a practical dense implementation for `n=22`. Results
describe the Syracuse model, not measured basin densities or the proof of
the Syracuse-potential conjecture.
